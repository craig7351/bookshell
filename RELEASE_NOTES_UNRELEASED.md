# Unreleased

- **Telnet connections** on Windows, Linux and macOS. Save a host and port, then sign in from the terminal tab.
- **Telnet 連線**支援 Windows、Ubuntu 與 macOS。儲存主機與連接埠後，可在終端分頁登入。
- **Serial (COM) — Windows only.** Open a local COM port in a terminal tab with configurable baud rate, framing, flow control, and line endings. On Ubuntu and macOS, imported Serial profiles are retained and marked Windows only.
- **串列埠連線（僅限 Windows 版）**。可在終端分頁開啟本機 COM 埠並調整鮑率、資料格式、流量控制和換行。Ubuntu 與 macOS 會保留匯入的 Serial 連線並標示僅限 Windows。
